# My Portfolio

A professional personal portfolio website showcasing my work in automation engineering, smart manufacturing, data-driven systems, and technical solution delivery.

## Overview

This portfolio is designed to present my background, core technical strengths, and selected real-world project experiences in a clear and modern format. It highlights my ability to bridge engineering, software, data, and industrial automation to deliver practical business outcomes.

The site is built as a lightweight static web portfolio using HTML, CSS, and JavaScript, making it fast, easy to maintain, and simple to deploy with GitHub Pages.

## Live Demo

[View Portfolio Website](https://dougchk.github.io/Portfolio/)

## What This Portfolio Showcases

This portfolio communicates the areas where I create value:

- **Automation Engineering** – building reliable systems for industrial and process environments
- **Smart Factory & IoT Integration** – connecting devices, systems, and data pipelines in manufacturing settings
- **Data Analytics & Visualization** – turning raw operational data into actionable insight
- **Application Development** – developing practical software tools and interfaces for engineering workflows
- **Technical Enablement** – helping engineers and researchers adopt tools such as MATLAB and Simulink effectively

## Built With
- **HTML5** – page structure and content
- **CSS3** – custom styling, layout, responsiveness, and visual design
- **JavaScript** – lightweight interactivity such as mobile menu behavior
- **GitHub Pages** – deployment and hosting
